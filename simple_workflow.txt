Here’s an improved, clearer, and well-structured **step-by-step guide** for your project setup involving local packages, virtual environment, MongoDB, logging, exception handling, and data ingestion:

---

## 🚀 **Project Setup & Virtual Environment**

### **Step 1: Create the Project Template**

* Run the `template.py` script to generate your initial project structure (folders and files).

---

### **Step 2: Setup for Local Package Imports**

* Modify the following files to enable local package imports:

#### 📄 `setup.py`

```python
from setuptools import setup, find_packages

setup(
    name="your_project_name",
    version="0.0.1",
    packages=find_packages(),
)
```

#### 📄 `pyproject.toml`

```toml
[build-system]
requires = ["setuptools"]
build-backend = "setuptools.build_meta"
```

> 💡 Refer to `crashcourse.txt` for more details on `setup.py` and `pyproject.toml`.

---

### **Step 3: Create and Activate Virtual Environment**

```bash
conda create -n vehicle python=3.10 -y
conda activate vehicle
```

---

### **Step 4: Add Dependencies and Install**

* Add required packages (like `pymongo`, `pandas`, `numpy`, `scikit-learn`, etc.) to `requirements.txt`.

```bash
pip install -r requirements.txt
pip list  # Verify installed packages
```

---

## 🗄️ **MongoDB Atlas Setup**

### **Step 5: MongoDB Atlas Account & Project**

* Sign up at [MongoDB Atlas](https://www.mongodb.com/cloud/atlas).
* Create a **new project** and give it a name.

---

### **Step 6: Cluster Setup**

* Click **“Create Cluster”**
* Choose **M0 (Free tier)** and continue with default settings.
* Click **“Create Deployment”**

---

### **Step 7: Create Database User**

* Go to **Database Access** and create a new user by setting a **username & password**.

---

### **Step 8: Network Access**

* Go to **Network Access** and **add IP address `0.0.0.0/0`** to allow global access.

---

### **Step 9: Get MongoDB Connection String**

* Go to **Database > Connect > Drivers**
* Choose **Driver: Python, Version: 3.6 or later**
* Copy the connection string and **replace `<password>`** with your actual password.

---

### **Step 10: Setup Notebook for MongoDB**

* Create a folder named `notebook`.
* Inside it, create a file: `mongoDB_demo.ipynb`
* Choose kernel: **Python > vehicle**

---

### **Step 11: Add Dataset**

* Add your dataset (CSV, JSON, etc.) to the `notebook` folder.

---

### **Step 12: Push Data to MongoDB**

* Use `pymongo` in the notebook to connect and insert the dataset into MongoDB.

---

### **Step 13: Verify Data in MongoDB**

* Go to **MongoDB Atlas > Database > Browse Collections**
* View your data in **key-value** format.

---

## 🧾 **Logging & Exception Handling**

### **Step 14: Setup Logging**

* Create a `logger.py` file to configure and initialize logs.
* Test it by importing and using it in `demo.py`.

---

### **Step 15: Setup Exception Handling**

* Create a `exception.py` file to define custom exceptions.
* Test it using `demo.py`.

---

## 📊 **EDA and Feature Engineering**

### **Step 16: EDA & Feature Engineering Notebook**

* Add EDA and feature engineering code to a notebook inside the `notebook` folder.

---

## 📥 **Data Ingestion Pipeline**

### **Step 17: Code Structure for Data Ingestion**

1. **Initialize Constants**

   * Add required variables in `constants/__init__.py`

2. **MongoDB Connection Code**

   * Write a reusable function in `configuration/mongo_db_connection.py`

3. **Data Access Logic**

   * In `data_access/proj1_data.py`, connect to MongoDB, fetch data, and convert to a DataFrame.

4. **Configuration Entity**

   * In `entity/config_entity.py`, define `DataIngestionConfig` class.

5. **Artifact Entity**

   * In `entity/artifact_entity.py`, define `DataIngestionArtifact` class.

6. **Data Ingestion Component**

   * Implement `DataIngestion` class in `components/data_ingestion.py`.

7. **Training Pipeline**

   * Add integration logic in `pipeline/training_pipeline.py`

8. **Run Demo Script**

   * Test the pipeline by running `demo.py` (ensure MongoDB URL is set, see next step).

---

### **Step 18: Set MongoDB Connection String (Environment Variable)**

#### 🖥️ For **Linux / Mac (Bash)**:

```bash
export MONGODB_URL="mongodb+srv://<username>:<password>@cluster.mongodb.net/"
echo $MONGODB_URL
```

#### 💻 For **Windows (PowerShell)**:

```powershell
$env:MONGODB_URL = "mongodb+srv://<username>:<password>@cluster.mongodb.net/"
echo $env:MONGODB_URL
```

#### 🪟 Windows GUI Method:

* Go to **System Properties > Environment Variables**
* Add New:

  * **Name**: `MONGODB_URL`
  * **Value**: your MongoDB connection URL
